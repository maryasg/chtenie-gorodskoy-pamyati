Откройте **cmd** (PowerShell открывать не нужно — `.bat` сам вызовет его для копирования в папки с русскими буквами в пути):


Скрипт создаст папку v16 на рабочем столе и скопирует туда файлы.

В папке **archiview_cv_easy_v16_package** на рабочем столе:

```bat
install_windows.bat
ZAPUSK_V16.bat
```

**Проверка:** заголовок окна — **v16 polygon edit**, зелёная строка **★ Archiview CV v16 ★**.  
Первая вкладка — **«0. Дом и сравнение»** (одна страница: дом, данные, сравнения, маршрут).  
Если видите **v15** — открыта папка `archiview_cv_easy_v15_package` (не та).

## Работа (вкладка «0. Дом и сравнение»)

На одной странице:

1. **Дом** — компактный список слева (прокрутка). Двойной клик или «Открыть». Справа — **папка, название, код MOSCOW_XXX, адрес, координаты**. **«Сохранить данные дома»**.
2. **Сравнения** — таблица ниже: **«Сделать текущим ★»** или двойной клик. Новое — **«Создать новое…»**. Если фото ещё нет — **«Добавить фото…»** или автоматический переход на **«7. Источники (старая)»**.
3. **Тип пары** — похожие ракурсы → **Выпрямление (4 угла)**; разные → **Сравнение side-by-side**. Синяя кнопка ведёт на нужную вкладку.

На вкладке **«2. Выпрямление»** шаг выбора фото убран — фото берутся из сравнения ★. Дальше: **шаг 2 — 4 угла**, **шаг 3 — наложение**.

При **«Создать новое…»** можно выбрать **выпрямленное modern** из другого сравнения (с превью).

Сохранение и **«Отправить на сайт»** — из папки сравнения со **★**.

Старая вкладка **«7. Источники (старая)»** — добавление исторического и современного фото (и для нового сравнения без фото).

## Предпросмотр на сайте (localhost)

На вкладке **5. Результат** — зелёная кнопка **«Показать на сайте (localhost)»**:

1. Копирует вашу разметку в `public/explorer/MOSCOW_NNN/` (как «Отправить на сайт», но без GitHub).
2. Запускает `npm run dev` в папке проекта сайта (если ещё не запущен).
3. Открывает страницу дома в браузере.

**Один раз** в cmd (если ещё не делали):

```bat
cd C:\Users\Marusia\Projects\chtenie-gorodskoy-pamyati
npm install
```

Нужен **Node.js** (https://nodejs.org/). Код дома — в поле «Код на сайте» (MOSCOW_001 …).

## Редактирование областей (новое в v16)

1. Вкладка **4. Разметка**
2. В списке **«Области»** выберите номер
3. **«Редактировать точки выбранной области»**
4. Тяните жёлтые точки мышью
5. Клик **по линии** — новая точка
6. **Delete** или **Backspace** — убрать выбранную точку (сначала кликните по ней; минимум 3). Или кнопка **«Удалить выбранную точку»**
7. **«Ниже (под другие)»** / **«Выше (над другие)»** — порядок слоёв, если большая область перекрывает мелкие (номер `id` не меняется)
8. **«Завершить редактирование»** — выйти из режима
9. **Сохранить разметку** — как раньше

Номера областей (`id`) и связи `traceId` на сайте при правке **не сбрасываются**.

В режиме «два окна» (разные ракурсы) редактирование точек пока недоступно — только overlay (одно окно).

На вкладке **Разметка** — кнопки **+** и **−** для масштаба, колесо мыши тоже работает.

## Несколько сравнений на один дом

Сравнения **не создаются автоматически** — только вручную:

1. Вкладка **«0. Дом и сравнение»** → **«Создать новое…»** (или **«Добавить фото…»**, если фото ещё нет)
2. **«Сделать текущим ★»** — углы, выпрямление, разметка, экспорт идут из этой папки
3. Лишние пустые `cmp_XXX` — **«Пометить к удалению»** → **«Удалить помеченные…»**

**Синяя строка под вкладками** всегда показывает ★ и `cmp_XXX` — на каком сравнении вы сейчас работаете. Если меняете современное фото на «7. Источники», это меняет фото у **активного** сравнения; для новой пары — сначала **«Создать новое…»**.

**На сайт:** при «Отправить на сайт» в корень попадает сравнение со **★**, а все остальные сравнения **с разметкой** — в `comparisons/cmp_XXX/` внутри папки дома на сайте. На странице дома появится переключатель вариантов.

Основная старая разметка часто в **`cmp_legacy_001 (legacy)`** — это зеркало папки `result/`.  
Если не нужна — включите **«Скрыть legacy»** в списке сравнений и работайте только с `cmp_008` и др.

При **«Создать новое…»** можно выбрать **выпрямленное modern** из другого сравнения (с превью).

**●** в списке исторических фото — только выбор фото для углов. **★** в таблице сравнений — какая папка работы активна. Это разные вещи.
