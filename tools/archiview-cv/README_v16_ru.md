```bat

```

В заголовке окна должно быть: **Archiview CV v16 polygon edit + stable site links**.

## Новое в v16

- **Редактирование точек полигона** — не нужно удалять область и рисовать заново:
  1. В списке «Области» выберите номер.
  2. Нажмите **«Редактировать точки выбранной области»**.
  3. Тяните жёлтые точки мышью.
  4. Клик **по линии** полигона — добавить новую точку.
  5. **Delete** — убрать выбранную точку (минимум 3 точки).
  6. **«Завершить редактирование»** — выйти из режима.
- **Стабильные номера областей** — при правке полигона `id` не меняется; связи `traceId` на сайте сохраняются при экспорте.
- **Новая область** — рисуете как раньше; на сайте появится без кураторского текста, пока не привяжете на кураторской странице.

Всё из v15: рука при пробеле, список областей, удаление любой, два окна для side-by-side.

## Если разметка пропала в Archiview

1. Проверьте **другое сравнение** (★) во вкладке «Сравнения».
2. Рядом с `manual_annotations.json` может быть **`manual_annotations.json.bak`** — переименуйте в `.json`.
3. Восстановление с сайта (дом со зверями = MOSCOW_003):

```powershell
cd C:\Users\Marusia\Projects\chtenie-gorodskoy-pamyati\tools\archiview-cv
powershell -ExecutionPolicy Bypass -File .\restore_markup_from_website.ps1 -CardId MOSCOW_003
```

Скрипт спросит имя папки проекта в `archiview_projects` и скопирует `annotations.json` с сайта обратно в Archiview.
