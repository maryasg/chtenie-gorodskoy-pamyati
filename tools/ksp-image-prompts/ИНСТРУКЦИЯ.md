## 1. Что куда попадает

| Что | Где лежит |
|-----|-----------|
| Список тем по месяцам | `content_plan\` (например `май.json`) |
| Промпты для ИИ | `prompts\` |
| Готовые статьи и картинки | `output\` — `.md` и `.docx` (только на ПК) |
| Плоские файлы за месяц | `статья01_июнь_2026_ВК_...docx`, `статья01_июнь_2026_ТГМАКС_...docx`, `картинка_...png` |
| Промпты для ChatGPT (обложки) | `image_prompts\` — только `.txt`, **не Word** |
| Ключ API | `.env` (секрет, не выкладывать) |

После генерации одной темы:

```
output\май\01-krovotochivost-desen-kogda-eto-uzhe-zabolevanie\
  vk.md
  vk.docx
  telegram.md
  telegram.docx
  image_prompt.txt   ← промпт для картинки (по тексту статьи)
  cover.png          ← обложка 16:9 (если генерировали картинку)
  meta.json          ← created_by: user
```

Плоские файлы в **той же** папке месяца (команда `pack_month.bat`):

```

  список_статей_июнь.txt
```

## 2. Настройка один раз (Windows)

Откройте **cmd** (чёрное окно):

```bat
cd C:\Users\Marusia\Projects\maryasg-articles_KorolevSP
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
notepad .env
```

В `.env` вставьте ключ **KupiAPI** (для текстов):

```env
OPENAI_API_KEY=rk_live_ваш-ключ
OPENAI_BASE_URL=https://kupiapi.ru/v1
TEXT_MODEL=gpt-5.4-mini
TEXT_MODEL_FALLBACK=gpt-4o-mini,gpt-4o,gpt-5.4,chatgpt-4o-latest
```

По гайду KupiAPI для Python: https://kupiapi.ru/instructions/python  

По словам поддержки KupiAPI для генерации сейчас стабильнее **только GPT**.  
Проверка моделей: `test_kupiapi.bat`.

Имена `kupi-*` — только для Cursor Agent. В `generate.py` используйте обычные id: `gpt-5.4-mini`, `gpt-4o-mini`.

Если основная модель недоступна, скрипт сам пробует другие GPT.

**Важно:** KupiAPI **не делает картинки** — только тексты. Обложки — через ChatGPT вручную или отдельный сервис (см. раздел 5 и `SERVICES.md`).

Перед каждой работой в cmd:

```bat
cd C:\Users\Marusia\Projects\maryasg-articles_KorolevSP
.venv\Scripts\activate
```

## 3. Как добавить новый месяц и темы

### Способ А — проще (рекомендуется)

1. Откройте в Блокноте папку `content_plan\`.
2. Создайте файл, например **`август.json`**.
3. Вставьте темы в таком виде:

```json
[
  {
    "month": "август",
    "number": "01",
    "title": "Заголовок первой статьи"
  },
  {
    "month": "август",
    "number": "02",
    "title": "Заголовок второй статьи"
  }
]
```

- `month` — название месяца **строчными** русскими буквами (`август`, `сентябрь`).
- `number` — `01`, `02`, … `15` (две цифры).
- `title` — заголовок статьи.

4. Добавьте те же темы в **`content_plan\all.json`** (в конец списка).

5. Обновите промпты для картинок (если скрипт уже установлен):

```bat
build_image_prompts.bat --force
```

### Способ Б — через скрипт (много месяцев сразу)

1. Откройте `build_content_plan.py` в редакторе.
2. В словарь `PLAN` добавьте новый месяц:

```python
"август": [
    "Первая тема",
    "Вторая тема",
],
```

3. Запустите:

```bat
python build_content_plan.py
```

Скрипт пересоздаст все файлы в `content_plan\` и `all.json`.

## 4. Как генерировать статьи (тексты)

Всегда сначала **активируйте** окружение:

```bat
cd C:\Users\Marusia\Projects\maryasg-articles_KorolevSP
.venv\Scripts\activate
```

### Одна пробная статья (без правки JSON)

```bat
python generate.py --title "Кровоточивость дёсен: когда это уже заболевание" --month май --number 01 --skip-images
```

### Весь месяц — только тексты (без картинок)

```bat
python generate.py --plan content_plan\май.json --skip-images
```

### Одна тема из плана месяца

```bat
python generate.py --plan content_plan\июнь.json --number 03 --skip-images
```

### Тексты + картинки через API (если настроен IMAGE_API_KEY)

```bat
python generate.py --plan content_plan\май.json
```

### Перегенерировать заново (если текст не понравился)

```bat
python generate.py --plan content_plan\май.json --number 05 --skip-images --force
```

### Что проверить после генерации

Откройте `vk.md` и `telegram.md` в Блокноте. Скрипт проверяет:

- объём VK ~2500–3000 символов, Telegram ~1200–1500;
- телефон `8 (499) 490-55-55` и ссылка на запись;
- хэштеги в одной строке;
- статья начинается с 🦷.

Замечания — в консоли и в `meta.json` → `validation_issues`. Если есть замечания — перечитайте текст и при необходимости запустите с `--force`.

## 5. Как делать картинки (обложки 16:9)

### Вариант 1 — ChatGPT вручную (основной, если нет IMAGE_API_KEY)

**Шаг 1.** Убедитесь, что есть папка `image_prompts\` и скрипт `build_image_prompts.bat`.

Если их нет — из репозитория сайта:

```bat
cd C:\Users\Marusia\Projects\chtenie-gorodskoy-pamyati
git pull
tools\ksp-image-prompts\СКОПИРОВАТЬ_В_СТАТЬИ.bat
```

**Шаг 2.** Соберите промпты:

```bat
cd C:\Users\Marusia\Projects\maryasg-articles_KorolevSP
build_image_prompts.bat --force
```

**Шаг 3.** Откройте нужный файл, например:

`image_prompts\май\01-krovotochivost-desen-kogda-eto-uzhe-zabolevanie.txt`

Полный список — в `image_prompts\INDEX.md`.

**Шаг 4.** Скопируйте весь текст → вставьте в ChatGPT (режим генерации картинки) → формат **16:9**.

**Шаг 5.** Сохраните картинку как `cover.png` в папку темы:

`output\май\01-krovotochivost-desen-kogda-eto-uzhe-zabolevanie\cover.png`

Если статья уже сгенерирована, в `output\...\image_prompt.txt` лежит промпт с **полным текстом** Telegram — его тоже можно использовать.

### Вариант 2 — автоматически через API

В `.env` добавьте блок для картинок (ProxyAPI, OpenAI и т.д. — см. `SERVICES.md`):

```env
IMAGE_API_KEY=ваш-ключ
IMAGE_BASE_URL=https://api.proxyapi.ru/openai/v1
IMAGE_MODEL=dall-e-3
IMAGE_SIZE=1792x1024
```

Только обложки (тексты уже есть):

```bat
python generate.py --plan content_plan\май.json --images-only
```

Одна обложка:

```bat
python generate.py --plan content_plan\май.json --number 03 --images-only
```

### Вариант 3 — текст и картинка сразу

```bat
python generate.py --plan content_plan\май.json --number 01
```

(нужны и текстовый, и картиночный API-ключ)

## 8. Частые проблемы

| Сообщение | Что делать |
|-----------|------------|
| `OPENAI_API_KEY не задан` | Создайте `.env` из `.env.example`, вставьте ключ |
| `build_image_prompts.bat` не найден | Запустите `СКОПИРОВАТЬ_В_СТАТЬИ.bat` из `chtenie-gorodskoy-pamyati\tools\ksp-image-prompts\` |
| В `output\июнь\` только подпапки, нет `статья01_...docx` | Запустите **`СОБРАТЬ_ПЛОСКИЕ_ФАЙЛЫ.bat июнь`** из папки статей |
| `pack_month.bat` не найден | `СКОПИРОВАТЬ_В_СТАТЬИ.bat` или `СОБРАТЬ_ПЛОСКИЕ_ФАЙЛЫ.bat` |
| `python` не найден | Установите Python 3.10–3.13, перезапустите cmd |
| Объём статьи не тот | `--force` или правка вручную в `.md` |
| Картинка не нравится | Удалите `cover.png`, снова ChatGPT или `--images-only --force` |
| Списание с баланса | Тексты — KupiAPI; картинки — отдельный сервис или ChatGPT |

## 9. Что можно править под себя

| Файл | Зачем |
|------|-------|
| `prompts\vk_system.txt` | Тон и правила статей для ВК |
| `prompts\telegram_system.txt` | Правила для Telegram |
| `prompts\cover_template.txt` | Шаблон промпта обложки (с текстом статьи) |
| `prompts\cover_template_title.txt` | Шаблон промпта только по заголовку |

После правки промптов — `--force` при следующей генерации.

После генерации одной темы пересоберите Word для уже готовых `.md`:

```bat
export_docx.bat --filter-month июнь
```

**Важно:** в `image_prompts\июнь\` лежат только промпты для картинок (`.txt`). Файлы Word появляются в `output\июнь\...` только после `generate.py` или `export_docx.bat`.

### Плоские файлы в папке месяца (проще всего)

**Одна команда** — копирует скрипты, при необходимости генерирует тексты, собирает файлы:

```bat

СОБРАТЬ_ПЛОСКИЕ_ФАЙЛЫ.bat июнь
```

Или из папки сайта:

```bat
СОБРАТЬ_ПЛОСКИЕ_ФАЙЛЫ.bat июнь
```

Если нужны файлы **без подпапок** — по одному набору на статью:

| Файл | Содержимое |
|------|------------|
| `список_статей_июнь.txt` | нумерованный список тем |
| `статья01_июнь_2026_ВК_...docx` | текст для ВКонтакте (Word) |
| `статья01_июнь_2026_ТГМАКС_...docx` | текст для Telegram (Word) |
| `картинка_месяц01_июнь_как-остановить.png` | обложка (если есть `cover.png` в подпапке) |

В имени — **первые 2 слова** заголовка по-русски; старые файлы (в т.ч. `.ARTICLE`) удаляются при пересборке.

```bat

pack_month.bat июнь
```

Только список тем (статьи ещё не готовы):

```bat
pack_month.bat июнь --list-only
```
