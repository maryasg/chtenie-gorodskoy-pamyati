Откройте **cmd**:

```bat

```

```env

OPENAI_BASE_URL=https://kupiapi.ru/v1
TEXT_MODEL=gpt-4o-mini
```

## 2. Как добавить новый месяц

Откройте папку:

`content_plan\`

Создайте файл, например:

`август.json`

Шаблон:

```json
[
  {
    "month": "август",
    "number": "01",
    "title": "Заголовок первой статьи"
  },
  {
    "month": "август",
    "number": "02",
    "title": "Заголовок второй статьи"
  }
]
```

Правила:

- `month` — русскими буквами, маленькими.
- `number` — `01`, `02`, `03`...
- `title` — заголовок статьи.

Если хотите, добавьте те же темы в `content_plan\all.json`.

---

## 3. Как сгенерировать статьи

### Весь месяц

```bat
python generate.py --plan content_plan\август.json --skip-images
```

### Одна статья из месяца

```bat
python generate.py --plan content_plan\август.json --number 03 --skip-images
```

### Одна пробная статья без JSON

```bat
python generate.py --title "Почему кровоточат дёсны" --month август --number 01 --skip-images
```

После генерации тексты лежат здесь:

```bat
output\август\01-...\vk.md
output\август\01-...\telegram.md
```

---

## 4. Как собрать удобные файлы для публикации

Самый простой вариант:

```bat
СОБРАТЬ_ПЛОСКИЕ_ФАЙЛЫ.bat август
```

Скрипт:

1. проверяет, есть ли статьи;
2. если нет — генерирует их;
3. собирает плоские файлы в `output\август\`.

В результате появятся файлы:

```bat
месяц01_август_..._вк.rtf
месяц01_август_..._телеграм.txt
картинка_месяц01_август_....png
```

## 5. Как делать картинки

### Вариант 1 — вручную через ChatGPT

Сначала соберите промпты:

```bat
build_image_prompts.bat --force
```

Промпты лежат здесь:

```bat
image_prompts\август\
```

Откройте нужный `.txt`, вставьте в ChatGPT и попросите картинку **16:9**.

Сохраните картинку как:

```bat
output\август\01-...\cover.png
```

После этого снова запустите:

```bat
СОБРАТЬ_ПЛОСКИЕ_ФАЙЛЫ.bat август
```

## 6. Что отправлять в публикацию

Для ВК:

- файл `..._вк.rtf`

Для Telegram:

- файл `..._телеграм.txt`

Для обложки:

- файл `картинка_....png`
