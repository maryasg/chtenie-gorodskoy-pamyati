Панель работы: статьи КСП

Куда кликать по порядку: темы → проверка API → генерация → промпты картинок → плоские Word-файлы.

Самый простой старт на Windows: дважды кликните ЗАПУСК_ПАНЕЛИ.bat — откроется окно с кнопками. Эта HTML-страница — подсказка «что куда». Рабочая папка проекта статей: C:\Users\Marusia\Projects\maryasg-articles_KorolevSP

1 Темы на новый месяц

Кнопки есть только в окне после ЗАПУСК_ПАНЕЛИ.bat (не в этом HTML).

  1. Выберите месяц и год сверху в окне панели.
  2. Нажмите зелёную кнопку «СОЗДАТЬ ТЕМЫ НА НОВЫЙ МЕСЯЦ».
  3. Откроется файл content_plan\темы_октябрь_2026.txt — пишите темы по одной на строку.
  4. Сохранить: Ctrl+S (или Файл → Сохранить).
  5. Вернитесь в панель → оранжевая кнопка «Готово: сохранить план для генерации».
  6. План генератора: content_plan\октябрь_2026.json (поля month + year).
  7. Статьи будут в output\октябрь_2026\ — разные годы не смешиваются.

2 Проверить KupiAPI

Без рабочего ключа генерация статей через ИИ не пойдёт.

  1. Файл .env в папке статей (ключ rk_live_…).
  2. Запуск: test_kupiapi.bat или кнопка в панели.
test_kupiapi.bat Инструкция

3 Сгенерировать статьи

В панели выберите месяц → «Сгенерировать весь месяц». Или в cmd:

python generate.py --plan content_plan\октябрь.json --skip-images

  1. Готово в output\октябрь\ — папки статей, vk.md, Telegram.
  2. Одна статья: укажите номер, например 03.

4 Промпты для картинок

После текстов соберите TXT-промпты для обложек.

  1. Кнопка «Собрать промпты» или build_image_prompts.bat.
  2. Результат: папка image_prompts\.
  3. Для уже готовых ручных месяцев смотрите .txt рядом со статьёй или ПРОМПТЫ_ДЛЯ_КАРТИНОК_ПО_ВК.txt.
