## Archiview v16 — вкладки

| № | Вкладка |
|---|---------|
| 0 | Дом и сравнение (wizard) |
| 1 | Источники |
| 2 | Выпрямление |
| 3 | Сравнение (overlay / до-после) |
| 4 | Разметка |
| 5 | Результат + **localhost** |

**★** в таблице сравнений = активная папка (`comparisons/index.json`).

**Legacy** `cmp_legacy_001` = зеркало `result/`. Скрыть с сайта: «Скрыть с сайта / к удалению». На экспорт **не попадает**.

**Годы** в таблице: кнопка «Указать годы…» (005: 1924→2026, 008: 1840→2026).
